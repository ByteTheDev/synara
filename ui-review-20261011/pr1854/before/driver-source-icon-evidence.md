# Beta source launcher native icon qualification

Before is exact main `9e01962e0b1e8fec9fb0e17f17a64017bc4eaf94`; After is the independently reviewed #1849 continuation #1854 at `4f7c61fe6f028d69ef187c9437286e7830628da4`. Both contain the same 1.0.3 package/dependency identity. The After tree preserves both original author feature blobs and history; the unrelated changelog blank-line prerequisite is explicitly included.

Two isolated macOS 26 runners set the actual supported `SYNARA_DESKTOP_FLAVOR=beta`, install the source's frozen runtime dependencies and Electron 43.4.1, and invoke the unchanged production `buildMacLauncher` function. Its existing command seam records and executes real `ditto`, `plutil`, `actool`, `codesign` and owned-bundle Launch Services commands. The verifier requires successful compilation of Stable's catalog Before and Beta's catalog After, a nonempty actual Assets.car, the canonical bundle identity, valid ad-hoc signature and byte-stable cache reuse without additional native commands.

The native observer asks `NSWorkspace.icon(forFile:)` for the generated bundle icon and renders that real AppKit image to a 1024-pixel PNG under the same light appearance. It does not launch the app or capture a running or closed Dock. These captures qualify source-bundle artwork, not app-picker interaction, packaged release generation, native process startup, a machine without actool, or a real legacy-cache/TCC migration. Those scope boundaries are distinct from the author's earlier macOS 27.0.1 images.

Every runner refuses a pre-existing generated runtime and existing/running Synara apps. Fresh generation cannot enter the stale-privacy-reset path; any attempt to invoke tccutil fails the diagnostic before execution. Cleanup unregisters only the owned generated bundle and removes only its initially absent runtime directory, including after a build failure. No user app, preference, credential or permission record is modified.

The After job also runs all 22 canonical launcher assertions on Darwin, including the actual ditto symlink-copy case. That test step uses the normal default source environment; the unchanged flavor regressions set their own explicit flavor inputs. The Before job qualifies actual native generation/rendering and does not claim to execute the newer regression suite. Source SHA/tree, checked-in launcher/test/identity/lock/bootstrap bytes, catalog inputs, actual native commands and statuses/signals, cache material, cleanup, copied test report and every evidence file hash remain recorded. Source cleanliness stays strict before installation, after installation/native execution and at finalization. Missing/failed native or test results fail the workflow; original failures are retained rather than replaced by a successful screenshot.

The synchronous native utility wrapper has bounded per-command timeouts and records actual status/signal/error separately. It makes no claim to clean up descendants of a timed-out utility; the disposable Actions job has a separate 30-minute bound. No release/tag, secret signing material, main write or auto-merge is involved.
